Reports

Review a project

Dashboard

See the configured projects, their GitLog rows, stored report count, latest run, and the average-complexity trend. Sync GitLog to import matching commits, or generate reports for one project or all projects.

Project reports

Choose a project to view its stored runs, their file count, function count, complexity averages per file and function, and a trend chart. Toggle each metric to change the chart.

Run summary

Open a stored run to inspect every included file. Sort by any metric column, filter Complexity, Functions, Complexity Total, or Complexity Average with minimum and maximum values, and select View functions to inspect a file's function entries. Table filters only change the rows shown; they do not change report metrics.

File exclusions

Add or remove project-specific exact paths or path patterns. Use % as a wildcard. Saved exclusions are persisted in config.json and immediately change visible dashboard, report, summary, and comparison metrics; original report data remains stored.

Comparisons

Compare two stored runs

Select runs

From a project's Compare section, select any two stored runs. The older timestamp is treated as the first run and the newer timestamp as the second run, regardless of selection order.

Read the result

Rows are matched by file path. The values in parentheses are the first and second run when they differ. A green row is a file added in the second run; a red row is a file that existed only in the first run.

Changes

For files in both runs, Complexity Change is second-run Complexity minus first-run Complexity. Average Change uses the same subtraction for Complexity Average. A plus sign means the value increased.

Scope

The same built-in and project-specific exclusions apply to comparisons. Excluded files do not appear and do not affect visible report-level statistics.

Calculations

How complexity values are computed

Function Complexity

The cyclomatic complexity reported for a function. The report uses ESLint's complexity result when available. Its fallback starts at 1 and adds the function's control-flow, expression, and default-parameter decision points.

Functions

The number of function entries found in the file.

Complexity

The file's stored complexity: the sum of its function complexities. When an imported function report has repeated function names in one file, this value counts each name once to retain the original report behavior.

Complexity Total

The sum of all function-entry complexities in the file, including repeated function names.

Complexity Average

File Complexity divided by Functions. A file with no functions has an average of 0.

Report Total Complexity

The sum of the included files' stored Complexity values.

Report Average Complexity

Report Total Complexity divided by the number of included files. It is an average per file, not an average of the file averages. A report with no included files has an average of 0.

Report Average Complexity Per Function

Report Total Complexity divided by the total number of included functions. A report with no included functions has an average of 0.

Built-in exclusions Files matching %eslint-configs/%, %mock%, %test-setup%, %.json, or libs/shared/% are always hidden from visible report statistics. Removing project exclusions does not restore these files.
